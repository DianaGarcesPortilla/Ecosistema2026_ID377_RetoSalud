# Documentación

Esta carpeta contiene la documentación gráfica y técnica utilizada en el proyecto.

Aquí se almacenan los diagramas metodológicos, la arquitectura de la solución, las figuras, las tablas y demás elementos visuales que complementan el archivo **README.md** principal del repositorio.

## Contenido

* **Figuras:** diagramas metodológicos, arquitectura de la solución, organización del repositorio, matrices de confusión y demás representaciones gráficas.
* **Tablas:** glosario, tecnologías utilizadas, resultados experimentales, métricas de evaluación y demás tablas incluidas en la documentación.
* **Evidencias:** imágenes del registro del modelo en MLflow y Unity Catalog, así como otras capturas relevantes del desarrollo del proyecto.

Los archivos de esta carpeta son referenciados desde el **README.md** principal mediante rutas relativas para facilitar la navegación y la documentación del proyecto.
