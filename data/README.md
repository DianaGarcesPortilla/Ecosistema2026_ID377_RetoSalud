#### Datos

Esta carpeta está destinada al almacenamiento de los conjuntos de datos utilizados en el proyecto.

#### Contenido

El proyecto emplea dos tipos de fuentes de información:

- Bases de datos públicas de **Datos Abiertos Colombia**.
- Bases de datos derivadas suministradas por el **Instituto Nacional de Medicina Legal y Ciencias Forenses (INMLCF)**.

#### Disponibilidad de los datos

Las bases de datos públicas pueden consultarse y descargarse desde el portal Datos Abiertos Colombia:

- Violencia intrafamiliar (2015–2024):
  https://www.datos.gov.co/Justicia-y-Derecho/Violencia-intrafamiliar-Colombia-a-os-2015-a-2024-/ers2-kerr/about_data

- Lesiones por Violencia de Pareja (2015–2024):
  https://www.datos.gov.co/Justicia-y-Derecho/Lesiones-por-Violencia-de-Pareja-en-Colombia-Hist-/9fs6-37ea/about_data

Las bases de datos derivadas del INMLCF **no se incluyen en este repositorio**, debido a restricciones de uso y distribución.

> Para una descripción detallada de las fuentes de información, el proceso de integración de datos y las características de cada conjunto de datos, consulte la sección **10. Datos utilizados** del `README.md` principal.
